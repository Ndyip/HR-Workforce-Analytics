# HR-Workforce-Analytics
An end-to-end Human Resources analytics project built with **SQL Server** and **Power BI**. This project transforms raw HR data into interactive dashboards that provide insights into workforce demographics, hiring trends, employee retention, and departmental performance.

---

## 📌 Project Overview

The goal of this project was to clean, transform, analyze, and visualize HR data to support data-driven workforce decisions.

The project follows a complete analytics workflow:

- Data Cleaning & Transformation (SQL Server)
- Exploratory Data Analysis (SQL)
- KPI Development
- Interactive Dashboard Design (Power BI)
- Business Insights & Recommendations

---

## 🎯 Business Objectives

- Clean and structure the HR dataset for analysis.
- Analyze workforce demographics.
- Monitor hiring trends over time.
- Measure employee retention and turnover.
- Evaluate departmental performance.
- Build an interactive dashboard for HR decision-making.

# 💡 Key Insights

- The organization maintains a predominantly active workforce.
- Employee tenure indicates strong long-term retention across several departments.
- Hiring trends fluctuate over time, providing insight into workforce expansion and recruitment cycles.
- Turnover varies by department, highlighting opportunities for targeted retention strategies.
- Interactive filtering enables detailed workforce exploration across multiple employee attributes.

# 📋 Recommendations

- Investigate departments with higher turnover rates to identify retention opportunities.
- Monitor hiring trends to support long-term workforce planning.
- Use high-performing departments as benchmarks for retention strategies.
- Continue tracking workforce metrics through interactive dashboards to support evidence-based HR decisions.
